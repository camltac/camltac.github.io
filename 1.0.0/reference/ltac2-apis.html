Ltac2 APIs#

This page documents the API of MLtac2 version 1.0.0.

Re-exports of Rocq APIs under their Ltac2 name.

Documentation on this file is adapted from the Ltac2 documentation and the reference manual.

Built-in types#

type ident = Names.Id.t
type evar = Evar.t
type cast = Constr.cast_kind
type constant = Names.Constant.t
type inductive = Names.Ind.t
type constructor = Names.Construct.t
type projection = Names.Projection.t
type pattern = Pattern.constr_pattern
type constr = EConstr.t
type preterm = Ltac_pretype.closed_glob_constr
type binder = Names.Name.t EConstr.binder_annot * EConstr.types
type message = Pp.t
type reference = Names.GlobRef.t
type err = Exninfo.iexn
type iexn = Exninfo.iexn
type exninfo = Exninfo.info
